# 150k 本地迭代日志:从"长旅程必死"到"自适应保真"

[English](ITERATION-150K.en.md) · [400k 实验报告](EXPERIMENT-REPORT.zh-CN.md) · [设计](DESIGN.zh-CN.md)

更新时间:2026-09-15。本日志记录在 400k 实验收束结论驱动下的修复-迭代循环:小步快跑、每轮一个变量、禁止大批量堆砌串行任务。全部结论来自真实模型旅程,原始证据在私有 `.test-runtime/experiments/context-150k-iter1/`。

## 背景与定位

400k 实验的定案结论:C 臂(插件 windowed)28/35 真实尝试死于同一结构性失败——保留输入越过有效预算线时无降级路径,旅程被直接终止。本迭代以**等比例缩放**(150k 压力线、432 页 ≈756k token、5× 压力比)在本地 Qwen3.8-27B(384K 档、单并发、reasoning low)上逐轮修复并验证。

**定位声明**:这是工程迭代证据(单任务、单种子、每臂单旅程),不是统计确证。它的作用是把缺陷逐个消灭并验证机制有效,不是宣称产品优越性。

## 自适应保真:设计与验证

设计(运营方提出):**摘要优先,模型自主判断充分性**——摘要足够则直答,需要精确值/逐字原文时才下探无损层。

v11 的验证形态:
- 摘要足够(更正追踪):零检索直答,6/6;
- 需要逐字:模型判断正确→有界检索(7 次)→3/3 精确取回——纯有损方案(B/A)结构性做不到的能力;
- 引擎层硬保证收敛(每轮 20 次授额上限,耗尽返回"立即作答"指引);
- 成本追平纯有损(5.9M vs 6.05M):无损不再意味着昂贵。

## 已修复缺陷清单(均有回归测试,changelog 同步)

1. 预算悬崖:有效线与物理线分离,有限超出记 `overshoot-within-physical-limit` 放行(§ W04b/W04c)
2. 轮内失忆:应急回退不再遮蔽最近表面节点
3. 回退风暴:步骤对齐保护 + 三口连吃 + 最近工作锚点
4. 用户消息保护:选择器无条件保护 + `eventAt` 下标修正 + 构造性保险(§ belt-invariant)
5. admission 硬线:同型软/硬分离
6. 无界检索:每轮硬限额 + 子串语义说明 + 突发授额池
7. 种子事实丢失:证据索引"标识符=引号值"形态 + 值排序淘汰(§ seed-fact-records)
8. 高压检索饿死:检索预算物理地板
